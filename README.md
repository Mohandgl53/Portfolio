## 🛠️ Quick Start Guide

### Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/Mohandgl53/Portfolio.git
cd Portfolio
npm install
```

### 2. Local Development Server
Start Vite's instant Hot Module Replacement (HMR) dev server:
```bash
npm run dev
```
Navigate to `http://localhost:3000` in your browser.

### 3. Production Build
Generate an optimized, standalone production distribution:
```bash
npm run build
```
The output will be built into the `dist/` directory.

### 4. Production Preview
Test the production build locally:
```bash
npm run preview
```

## 🚀 Deployment

This portfolio is configured for zero-friction deployment to any cloud hosting provider:

### Deploy to GitHub Pages (Automated)
A GitHub Actions workflow is provided at `.github/workflows/deploy.yml`. When pushed to the `main` branch:
1. Ensure GitHub Pages is enabled in your repository under **Settings $\to$ Pages**.
2. Select **Source: GitHub Actions**.
3. Pushing to `main` will automatically build and publish the portfolio live.

### Deploy to Vercel
1. Import the repository on [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.

### Deploy to Netlify
1. Connect repository on [Netlify](https://www.netlify.com).
2. Build Command: `npm run build`
3. Publish Directory: `dist`
4. Click **Deploy Site**.
